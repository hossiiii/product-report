国内既存プレイヤー

  • Urizo（ウリゾウ） — Google マップ・ぐるなび等 30+ サイトから企業情報・メールを収集する国内代表ツール。9,900 円/月から、1 件 1 円未満で SocLeads と直接競合。
  • Musubu / Baseconnect — 140 万社の企業 DB から営業リストを構築する SaaS。導入 61,000 社超。SNS スクレイピングは扱わないが、コールドメール用リストでは第一想起。
  • BIZMAPS — 無料 100 件/月 + 30 円/件の従量。5,000+ タグで業種絞り込みに強み。SocLeads の Free→Pro 導線と価格帯が重なる。
  • SalesNow — AI で 500 万社 DB を提供する新興競合。資金調達済みで広告・コンテンツ攻勢中。個人開発の SocLeads クローンには立ち位置確保が難しい。

規制要点

  • 特定電子メール法: SNS や Google マップから無断収集したメールアドレスへ広告メールを送る行為はオプトイン違反。総務省の改善命令を経て最大 1 年以下の懲役または 100 万円以下の罰金（法人は 3,000 万円）。社名公表もあり、SocLeads の正当な日本ユースケースは事実上 BtoB の公開連絡先で『送信拒否』表示なしの場合に限定される。
  • 個人情報保護法: メールアドレスは個人を識別できる場合に個人情報該当。スクレイピング取得した個人データを CSV で第三者提供・販売する行為は同意なく原則違法。リスト購入者側のリスクが高く、再販ビジネスモデルは成立困難。
  • 不正競争防止法 / 著作権法 / 各プラットフォーム規約: Instagram・LinkedIn・Facebook 等の規約は自動収集を明示禁止し、過去 LinkedIn vs hiQ 訴訟で米国は『公開データの収集合法』としつつも、最終的に hiQ は和解金支払いで撤退。日本でも DB の著作権・営業秘密性が争点化し得る。

機会: 国内既存プレイヤー（Urizo / Musubu / BIZMAPS / SalesNow）は『法人 DB ベース』で SNS インフルエンサー収集は手薄。例えば D2C ブランドの PR 用 Instagram マイクロインフルエンサー DM リスト、地方店舗向け Google マップ × 業種絞り込みリストといったニッチに絞れば差別化余地はある。ただし特定電子メール法の制約上、SaaS としては『公開 BtoB 連絡先＋オプトイン取得補助』機能をセットにして合法ライン上で運営する必要があり、価値提案を再設計しないと国内では売れない。

市場機会総評: 日本の営業リスト市場は既に飽和気味で、SocLeads の中核機能（SNS から無断でメールをスクレイプ）は特定電子メール法・個情法・SNS 規約のトリプルブロックに直撃する。SaaS としての demand 自体は確かに存在するが、合法に売れる範囲は『BtoB 公開連絡先』に縮退し、その領域では Urizo / Musubu / BIZMAPS / SalesNow が確固たるポジションを既に占有。SNS インフルエンサー DM 開拓という横展開ニッチも、Instagram のスクレイピング規約強化と DM 規制で時間とともに窮屈になっていく。海外プロダクトとしては既に Apollo / Hunter / Apify / Outscraper が日本にも流入しており、SocLeads の優位性（地域フィルタ・横串）は中程度。個人開発者が国内向けにクローンを作るインセンティブは弱く、verdict は skip。

判断ガイド

何をするか
SocLeads 3.0 は Instagram、Facebook、LinkedIn、YouTube、Twitter、Google マップ、TikTok といった主要 SNS と地図サービスから、キーワード・フォロワー・地理条件でメールアドレスを抽出する Web ベースのリードジェネレーション SaaS。プラグインやコード不要で、内蔵のメール検証によりバウンス率を 3% 以下に抑え、CSV/XLS ワンクリック出力に対応する。今回の v3 アップデートでは、Google マップの国・地域単位の一括検索、SNS の地理スクレイピング、1 クエリあたりの取得件数増加が目玉。営業チーム、マーケター、リクルーター、エージェンシーオーナーをターゲットに、ローカルビジネスや影響力のある SNS アカウントへのコールドアウトリーチ用リスト構築を高速化する。料金は無料 100 件、Pro $59/月 1 万件、Business $149/月 10 万件と段階制。
