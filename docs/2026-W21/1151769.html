判断ガイド

何をするか
Slideshotは、AIエージェント（Claude / Cursor / Codex / ChatGPT 等）にMCPで接続し、Webアプリのプロダクトフローを自然言語で指示するだけでデモ動画を自動生成するツール。エージェントが認証済み画面を含むブラウザを自律操作し、ズーム・カーソル移動・イントロアニメ・ブランド演出付きの完成MP4とGIFを返す。価格は録画した動画ごとの従量課金。主な用途はローンチ動画、changelog資産、ヘルプセンターのウォークスルー、機能アナウンス、カスタマーエデュケーション向け説明動画。プロダクトUIの変更に追従して動画を再生成しやすい点を訴求。Loom/Screen Studio/Tella のような録画ツールや Storylane/Arcade/Supademo のようなインタラクティブデモとは差別化軸が異なり、人間が録らずエージェントが録ること自体が中核プロポジション。
誰に刺さるか
ローンチ動画やchangelog動画を継続生成したいSaaSのプロダクトマーケター、UI変更に伴うヘルプ動画更新を自動化したいプロダクトチーム、サポート用ウォークスルーを量産したいCS / サポート担当。AIエージェント（Claude Code, Cursor等）を既に業務で使っているテック寄りチームと相性が良い。
再現可能性
hard — ブラウザ自動操作・MCP連携・録画と動画後処理（ズーム/カーソル/イントロ）の高品質パイプラインを一体で作る必要があり、個人開発で完成度を出すのは難易度高。
