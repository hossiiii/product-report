判断ガイド

何をするか
Dreambase Data Agent SkillsはSupabaseを中核にしたAIネイティブ分析プラットフォームの新機能で、データソース（Supabaseテーブル、Stripe、PostHog、任意のAPI/MCP）、ビジネスロジック、書式整形、可視化ルールを1つの再利用可能ユニット（Skill）にバンドルする。オンボーディング時にSupabaseスキーマを自動スキャンし、初期Skillセットをプリポピュレートする。プレーン言語のSkill Builderウィザードで追跡したい指標に応じたテーブル・コネクタを選択でき、エージェントはSkillをコンテキストとして読み込み必要に応じてライブでスキーマも解析する。CLIおよびMCP経由でのSkillアクセスも近々提供予定で、他のエージェントやプラットフォームからの消費も可能になる。FelicisとSupabase役員出資で$3.7M調達済み。
