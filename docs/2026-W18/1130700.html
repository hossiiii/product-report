規制要点

  • 個人情報保護法 (APPI): 海外SaaSとして利用者の個人データを取り扱うと「外国にある第三者への提供」規制が発動し、本人同意またはCBPR等の国際枠組み認定が必要。データを自端末側に閉じる設計でも外的環境把握・委託先管理は必須。
  • 電気通信事業法 (外部送信規律): アプリ/サービスから利用者の情報を外部送信する場合は、送信先・項目・利用目的の通知/公表が必須。アバターやモデルAPIへ送る情報の開示設計が必要。
  • 著作権法・景品表示法: AI生成物の著作権帰属、学習・公開挙動、無料Proキャンペーンなどの表示は景表法の規制対象。AIによる出力の二次利用ガイドの明示が望ましい。

判断ガイド

何をするか
KarmaBox は、スマホを司令塔として複数のAIエージェント（Claude Code、Codex、Gemini など）を、ユーザー自身の手持ち端末（Mac、PC、サーバー等）にまたがる「私設計算プール」上で並列稼働させるオーケストレーション・プラットフォーム。アバター（役割を持つAI）を自然言語で定義し、コードを書く・レビューする・画像を生成する・公開するといったタスクを一度のメッセージから自律実行する。データは自端末側に留まる「主権AI」を訴求しており、エンドツーエンド暗号化と、無料iOSアプリからの開始＋有料Proへのアップグレード（プライシング詳細は landing 上で開示されていない）が想定モデル。マルチデバイスのリアルタイム同期、最適モデルへの自動ルーティング、一括ソーシャル投稿などをまとめて提供する。
誰に刺さるか
複数のAIサブスクを並行契約しており、コピペ往復で消耗している個人開発者・ソロクリエイター・PoC実装家。通勤や移動中もスマホからエージェントへ指示を出し、自宅PCに重い処理を任せたいヘビーユーザー。プライバシー要件で自端末完結のオーケストレーションを求める層。
再現可能性
hard — iOS/デスクトップ双方のクライアント、デバイス間オーケストレータ、複数LLMルーター、E2E暗号化、UI設計まで全て自作必要。Claude Code 公式Remote Controlも登場済み。
