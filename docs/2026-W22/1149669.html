規制要点

  • 個人情報保護法: 収集対象は拡張ストアの公開メタデータ（インストール数・評価・レビュー等）が中心で、レビュー本文に含まれる個人名等の二次利用に留意すれば重い義務は発生しにくい。アカウント登録・課金に伴う最小限の個人情報管理で対応可能。

判断ガイド

何をするか
Chrome Web Store・Microsoft Edge Add-ons・Firefox Add-ons の 3 ストアを横断し、拡張機能のインストール数/評価/レビュー/カテゴリ順位/キーワード順位を日次収集して時系列で可視化する。自社拡張を 1 プロダクトにまとめ、競合を追加して横並び比較、レビューを 1 テーブルに集約、変化があれば Email/Slack でアラート。280K+ 拡張を 30+ フィールドで検索・ソートでき、1D/7D/30D の増減デルタや CSV/XLSX エクスポート、AI キーワード提案、ストア全体トレンド（拡張総数/開発者/ユーザー/レビュー量）も追える。典型ユースは、拡張ファウンダーが自社の順位低下や競合の動向を早期検知し、キーワード最適化や機能改善の意思決定に使うこと。
誰に刺さるか
ブラウザ拡張のファウンダー・個人開発者（インディーメーカー）、拡張を量産する代理店、拡張プロダクトを持つ小規模チーム。自社ストア管理画面では見えない時系列推移・競合比較・キーワード順位を必要とする層。
再現可能性
medium — UI とダッシュボードは標準的だが、3 ストア横断で 280K+ 拡張の日次データを継続収集・正規化するパイプラインとストレージ、レビュー 6M+ の蓄積が参入障壁。データ取得の安定運用が肝。

注目シグナル

  • PH で 227 upvotes・コメントでも『競合追跡が面白い半分』と評価され、機能の刺さりどころが明確
  • Chrome のみでなく Edge/Firefox を横断する点が一部競合より広いカバレッジ
  • 拡張開発者の課金実績は海外で存在（同カテゴリ $8〜49/月）
  • 365 日履歴・6M レビュー蓄積という時系列データ資産

懸念点

  • Chrome-Stats / Extension Radar / Extpose 等の先行競合が多数で差別化が薄い
  • データソースが各ストアの公開データ収集に依存し、ストア側の仕様変更や ToS リスクに脆弱
  • 対象が拡張開発者という狭いニッチで、しかも本質的に英語圏グローバル市場
  • 日本特有の需要・差別化要素がほぼ無い
