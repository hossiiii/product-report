Open Vibe

総合 5/10 日本 6/10 事業 5/10 consider

AI エージェントを SaaS 構築の家庭教師化する OSS。実アプリを作りながら認証・決済・DB の仕組みを学べる無料教材。

判断ガイド

何をするか
Claude Code や Cursor などのコーディングエージェントに読み込ませることで、エージェント自身が SaaS 構築の手順とその裏側にある概念（Git・HTTP・DB・デプロイ等）を生徒に教えてくれる OSS カリキュラム。Wasp フレームワークをベースに、認証・決済・AI 統合を含む実用 SaaS を題材として進行する。MIT・無料・サインアップ不要。
誰に刺さるか
Vibe Coding でアプリを作れるが裏側を理解していないアスピリングファウンダー、副業で SaaS を立ち上げたい非エンジニア、AI 駆動開発を体系的に学びたい学習者。
再現可能性
easy — MIT で全コード公開、Wasp + Claude Code/Cursor 等の標準ツールで構成。教材設計・図解アセット・プロンプト品質の作り込みは要するが技術的障壁は低い。
