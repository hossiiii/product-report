国内既存プレイヤー

  • Gemini (Google本家) — 対象プロダクトそのもの。Pro月額3,000円弱で日本でも全機能を日本語で利用可能。個人開発が乗り越える対象が本家になる根本構造。
  • ChatGPT Canvas (OpenAI) — 2026年3月にインタラクティブ可視化拡充。日本でChatGPT Plus契約者多数。月額20ドルで類似機能を提供済。
  • Claude Artifacts (Anthropic) — HTML/JSアーティファクトをチャット内で即実行可能。日本のエンジニア層に人気で教育用途にも転用される。
  • PhET (コロラド大学) — 無料・OSSの理科シミュレーション。日本語訳済(高知工科大訳)、三重県等で教員研修教材として実績、文科省関連の学校でも使用例。
  • atama+ (atama plus) — 国内AI個別最適化教材の代表格。約4,000教室で導入、学習塾・大学入学前教育まで拡大、フランチャイズも展開。

規制要点

  • 個人情報保護法: 学習履歴・解答ログを保存する場合は個情法対応必須。匿名化/利用目的明示/委託先管理(LLM API利用時)で通常運用範囲。
  • 景品表示法/特定電子メール法: 教材として効果を訴求する場合は誇大表現NG。LINE等での販促配信は事前同意取得必須。標準的なEdTech運用と同等。
  • 著作権法: 教材化に既存教科書図版を学習元として使うとリスク。生成物の著作権帰属とユーザーへの利用許諾範囲を明示する利用規約整備が必要。

機会: 本家機能の単純な模倣は不可。日本独自の角度を取るなら(a)文科省指導要領の単元名・用語に厳密準拠し中高教科書の章ごとに紐づくシミュレーションテンプレ集、(b)塾講師が授業中に5秒で出せる即時生成UI(板書連動)、(c)子供の理解度を可視化し保護者にレポーティングする家庭向け、のいずれかにスコープを狭める方向。PhETに無い「指導要領タグ付け×AI即時生成」が唯一の差別化軸。

市場機会総評: 日本市場での需要シグナル(媒体反応・PhET実績・atama+普及)は確認できるが、対象プロダクト自体が世界トップ3社の汎用AIに既に内蔵された機能であり、個人開発者が直接代替する余地は実質的にない。日本独自の文脈(指導要領準拠、教科書連動、塾講師ワークフロー)に絞ればニッチは残るが、それも教育市場の調達慣行(代理店・教委ルート)に阻まれB2B営業負荷が大。市場機会としては『観察するが、本家機能の延長線では参入しない』が妥当。watch相当だが、事業として推奨する強さは弱め。

判断ガイド

何をするか
Gemini Pro モデルに「show me」「visualize」と指示すると、分子構造・惑星軌道・二重振り子・物理法則・フラクタルなど複雑な概念を、チャット内でその場で操作可能な3Dモデル/インタラクティブ図表に変換する機能。スライダーで初速・重力など変数を変えて挙動を即時確認できる。実体は GeminiがHTML/CSS/JSコードを生成してiframeで実行する仕組みで、Canvas / Artifacts と思想は同じ。教師・学習者・個人開発者向けのプロトタイピング用途を想定。Education/Workspace アカウントは展開外。
誰に刺さるか
学習者(中高生〜大学生、社会人リスキリング)、教育コンテンツ制作者、自己学習で複雑概念を理解したい開発者、子供に説明したい保護者、概念を素早く可視化したいプロダクトマネージャー等。
再現可能性
hard — 技術的にはThree.js + LLMでHTMLサンドボックス生成すれば作れるが、Gemini/ChatGPT/Claudeすでに同等機能を無料〜¥3,000/月で提供、個人開発でユーザーが乗り換える理由を作れない。

注目シグナル

  • Qiita/HelenTech/ASCII/ITmediaなど主要日本テック媒体が即日記事化、関心度は高い
  • PhET日本語版が教員研修で既に普及、可視化教材ニーズの存在は実証済
  • OpenAI Canvas→Claude Artifacts→Gemini と3週間で出揃った=競争の激しさを示す
  • Education/Workspaceは未対応で、学校向け正式展開には時間差あり
  • Pro契約者向け先行=有料転換のドライバーとして本家が位置付け

懸念点

  • 本機能は単体プロダクトではなくGeminiアプリの一機能で、個人開発者が直接競合できる対象ではない
  • ChatGPT Canvas / Claude Artifacts と機能が事実上同等で、ユーザーは既に契約中のサービスで完結する
  • 国内教育市場はatama+/Qubena/Monoxer/ClassiがB2B営業で既に押さえており、PLGで個人が侵食する隙が小さい
  • PhETという無料OSSが日本語訳済みで物理/化学の標準教材として教員研修で普及している
  • 教育機関のIT調達は人脈・代理店経由が中心、個人開発者がリーチしづらい
