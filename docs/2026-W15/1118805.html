国内既存プレイヤー

  • formrun — 国産フォーム作成+顧客管理SaaS。ユーザ5万人、月額3,000円台〜のプラン。テンプレ120種で問い合わせ対応に強い。
  • Tayori — PR TIMES系の国産ツール。Starter月3,400円、Professional月7,400円。FAQやアンケートも統合管理。
  • Googleフォーム — 完全無料・無制限。Googleアカウントで即利用、スプレッドシート連携でデファクト。
  • Microsoft Forms — Microsoft 365付帯。Teams/Excel/Outlookと連携、企業ユーザに標準装備されている。

規制要点

  • 個人情報保護法(改正): 氏名・メール取得時は利用目的明示が必須。海外SaaSであるOnformを利用する場合は越境移転規制が適用され、所在国名等をプライバシーポリシーに記載する必要。自己ホスト版なら回避可能。
  • 特定電子メール法: リード獲得目的でメール送信する場合は事前オプトイン同意の取得と記録保存、配信停止導線の設置が必須。違反時1年以下の懲役/法人3000万円以下の罰金。フォームに同意チェックボックス設計が必要。

機会: もし日本人が攻めるなら『MCPで作る』は捨て、formrunが手薄な領域(自己ホスト/オンプレ要件のある士業・医療・自治体向け、または開発者向けの埋め込みSDKフォーム)に絞った国産OSSフォームビルダーが筋。Onformそのものの追従ではなく、Claude Code文化の日本人開発者がGitHub READMEに貼れるOSS form-builder + 国内決済対応(Stripe Japan/PayPay)+国内サーバ要件対応で差別化する手はある。ただし市場規模は極小。

市場機会総評: フォーム市場自体は国内でも巨大だが、Onformの主差別化『MCPネイティブ』は日本のエンドユーザにほぼ刺さらない。意思決定者は非エンジニアが多く、無料のGoogleフォームか実績豊富なformrunを選ぶ慣性が強い。Claude Code文化が浸透しつつあるとはいえ、利用者数の絶対値が小さく、その中で『フォームをチャットで作りたい』ジョブはさらに細い。海外でTypeform代替として大きく育っても、日本市場では既存の安価/無料選択肢で代替されてしまう可能性が高い。日本での独自勝ち筋は実質見えず、score 5/verdict skipが妥当。検索で根拠未確認の数値(国内MCP利用者数等)は控えめに評価した。

判断ガイド

何をするか
Onform.workは、MCP(Model Context Protocol)サーバを標準搭載した次世代フォームビルダー。ClaudeやCursorに「ウェイトリスト用フォームを作って、メールと会社名を聞いて」と話しかけるだけでフォームが生成・公開され、回答もAIから直接照会・エクスポートできる。13種のフィールド型、条件分岐、1問ずつ表示するチャット風モード、Docker一発の自己ホスティング、無制限の回答件数を売りにする。Founding.devという『AIで内製SaaSを置き換えるプラットフォーム』の最初のプロダクトという位置付け。典型ユースケースはリード獲得LP、ベータ版ウェイトリスト、社内アンケート、リサーチ用問診票など、AIエージェントを既に使っている開発者の手元でフォームを完結させる用途。
誰に刺さるか
Claude Code/Cursorを既に日常的に使う海外の個人開発者・小規模スタートアップ。ダッシュボードを開かずチャットで全てを済ませたい層、SaaS課金（特に回答数課金）を嫌い自己ホストや無制限プランを好むビルダー層がコアターゲット。
再現可能性
medium — フォームDB+ビルダー+MCPサーバ実装が必要。Next.js+Postgres+TypeScript SDKでMCPサーバを書くだけならOSSテンプレで2-4週、自己ホストとSLA考慮で本気実装は3ヶ月級。

注目シグナル

  • MCP互換ツールがClaude/Cursor/ChatGPTで標準化し配布チャネルが整備された(2026年4月時点で公開MCPサーバ1万本超)
  • 247 upvotes / 30コメントとPHでは中堅以上の関心度
  • $39/月で100件しか受け付けない既存ツール（Typeform想定）への明確なアンチテーゼ
  • 無制限プラン+自己ホスト+Docker一発という開発者好みの構成
  • MCPサーバを後付けプラグインではなく『内蔵』にする設計判断

懸念点

  • フォーム市場は世界的に飽和、MCPが付くだけで乗り換えが起きるかは未検証
  • AlphaトピックでPH掲載=まだプロダクト未成熟、収益モデル/プラン詳細も曖昧
  • ChatGPT/Claudeの公式コネクタやTypeform/Jotform自身のMCP対応で容易に追い抜かれる
  • 提出データ管理SaaSはGDPR/個情法対応・可用性監視で個人運用負荷が高い
  • 『話しかけてフォームを作る』のはUI操作より遅い場合が多く、本質的なジョブが弱い
