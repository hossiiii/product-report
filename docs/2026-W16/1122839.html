判断ガイド

何をするか
Claude Code / Codex / Cursor / Windsurf / Copilot など40以上のAIコーディングエージェントに対し、システムプロンプトで応答スタイルを「原始人口調（電文体・冠詞や枕詞を排除）」へ切り替えるOSSスキル/プラグイン。MITライセンス・ワンライナーインストール。Lite/Full/Ultra/文言文の4段階の圧縮強度を持ち、`caveman-commit`（≤50字コミットメッセージ生成）、`caveman-review`（一行PRコメント）、`caveman-compress`（CLAUDE.mdをcaveman化して入力トークンを約46%削減）など複数のサブスキルが同梱される。ベンチマークでは実コーディングタスクで出力トークン平均65%（22–87%）削減、応答速度は約3倍を主張。Anthropic公式Claude Code Pluginsディレクトリにも掲載。
誰に刺さるか
Claude Pro/Max・GPT/Codex・Cursor等のサブスク利用上限に頻繁にぶつかる個人開発者・スタートアップエンジニア。長文回答ではなく差分・結論のみを欲するコーディング用途のヘビーユーザー。CLAUDE.md等メモリファイルが肥大化して入力トークン圧迫を感じているチーム。
再現可能性
easy — システムプロンプト・スキル定義ファイルとシェルインストーラのみで構成され、特殊APIや独自バックエンド不要。caveman本家・genshijin等の派生も同等構造で再現済み。

懸念点

  • 本体OSS（MIT）でマネタイズ手段が事実上ない
  • Claude公式の出力トリミング・キャッシュ・/compact等で代替されつつある
  • 日本語特化はgenshijinが先行し、日本語派生のニッチは事実上埋まり済み
  • input tokenはむしろ増える（システムプロンプト常駐）— キャッシュ前提でないと逆効果のケースあり
  • AnthropicのMarketplaceは無料配布前提で課金導線が公式に存在しない
