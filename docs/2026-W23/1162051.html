  • Claude Code on the web（Anthropic） — Anthropic管理のクラウドVM上でClaude Codeを実行。複数セッション並行実行・定期タスクのスケジュール対応。Replicasと用途が直接重なる本家機能で、日本語ドキュメントも整備。

規制要点

判断ガイド

何をするか
ユーザーのリポジトリを隔離されたクラウドVMに展開し、依存関係インストール・DB起動まで含む実動環境を用意した上で、Claude Code / Codex / OpenCode などのコーディングエージェントをバックグラウンドで並列実行する基盤。harness（エージェント本体）にロックインせず、APIキーやサブスクはユーザー持ち込み（BYO）で、課金対象はインフラのみ。GitHubのPRで @replicas メンション、Slackでの依頼、Linearのissueアサイン、API直叩きなど既存ワークフローからトリガーでき、完了するとレビュー可能なPRが返る。典型用途はPRレビュー自動化、CIでのコード品質チェック、セキュリティレビュー、issueの自動トリアージ、常時稼働のオンコール対応。リモートデスクトップ/SSHで作業中セッションを直接プレビューでき、人と人/AIのハンドオフ（マルチプレイヤー）も可能。自社では生涯PRの95%をReplicas経由で出荷、顧客平均でもPRの30%が本サービス経由とされる。
誰に刺さるか
複数機能を並行開発するスタートアップ〜中規模エンジニアリングチーム、PRレビューやCIチェックを自動化したいDevOps/プラットフォームチーム、ローカルマシンを開けっ放しにせずバックグラウンドでエージェントを回したい開発者。harnessの選択自由度とBYO鍵を重視する技術志向の組織が中心。
再現可能性
hard — 隔離VMのオーケストレーション、各リポジトリの環境再現、ネットワーク制御、複数harness対応、Slack/Linear/GitHub連携を統合する必要があり、個人での実装・継続運用は難度が高い。

注目シグナル

  • YC（P26）採択、MintlifyやComposio等の実顧客あり
  • harnessにロックインしないBYOアーキテクチャで本家ラボの新機能を即利用できる差別化
  • PRレビュー・CI品質チェック・オンコール等、コーディング超えのユースケース拡張

懸念点

  • Devin（Cognition日本法人）・Cursor Background Agents・Claude Code on web 等の強力な先行プレイヤーと正面競合
  • 顧客のソースコードを外部VMで実行するため機密性・セキュリティ要件が厳しく日本企業の審査ハードルが高い
