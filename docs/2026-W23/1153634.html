判断ガイド

何をするか
GitHub・Linear・Jira・Notion・Slack などの既存ツールを監視し、そこで下された製品上の意思決定（なぜこの設計か、何を見送ったか、顧客が何を求めたか）を20以上のエージェントが自動抽出して「Product Graph」という検索可能な知識グラフに構造化する。新しいコーディングエージェント（Cursor / Claude Code / Windsurf / VS Code 等）に MCP・CLI 経由で必要な文脈だけを注入し、過去の決定に沿った実装を促す。Web アプリで決定の閲覧・検索、Slack/チャットで人間も質問可能。ベンチマークでは決定遵守率46%→95%、8/8タスクがマージ可能、マージあたりコスト68%減と主張。
誰に刺さるか
AIコーディングエージェントを本格運用する開発チーム。インディーハッカー〜アーリーステージのスタートアップ（製品戦略パートナーとして）、スケールアップ企業（意思決定の番人として）、AI先進エンタープライズ（変革の増幅装置として）を想定。Linear/Jira/Notion/Slack/GitHub を日常的に使うチームが前提。
再現可能性
hard — MCP/CLI 配線は容易だが、複数ツールからの自然言語の意思決定抽出・グラフ化・鮮度維持を高精度で行うパイプラインが中核価値で、日本語テキスト対応も含め個人での品質再現は難しい。

  • Notion/Atlassian/Linear など連携元の各社が同等の文脈・メモリ機能を内製化しつつある
