国内既存プレイヤー

  • ScreenPointer — 日本人開発者 Kyome のマウス強調アプリ。無料+App内課金 Pro で19種のポインタ。プレゼン/画面共有の定番として国内で広く認知。Presentify とカーソル強調が直接競合。
  • DemoPro - Screen Annotation — 約300円の Mac 用画面注釈アプリ。ホットキーで画面に描画、ホワイトボード・タイマー対応。Presentify の注釈機能とほぼ正面から競合する低単価買い切り。
  • ZoomIt for Mac (Microsoft Sysinternals) — Windows 定番のズーム/注釈ツールの macOS 版を Microsoft が無料提供。ズーム＋描画のコア機能を無料で代替でき、価格競争上の脅威。
  • macOS 標準ズーム機能 — OS 標準のアクセシビリティでカーソルズーム/画面拡大が可能。簡易用途は OS だけで足りるため、有料化の天井になる。

規制要点

市場機会総評: 需要自体は存在するが、これは『日本市場の隙間』ではなく『世界共通で需要がある成熟カテゴリ』。国内には日本人開発の ScreenPointer が定番として根付き、DemoPro・Scribbble・ZoomIt for Mac・macOS 標準ズームと代替が層をなす。さらに評価対象の Presentify 自身が既に日本の App Store で約¥1,000買い切り＋Setapp で流通し、note/Qiita でも紹介済み。つまり『日本向けにローカライズして新規開発する余地』はほぼ埋まっている。規制・ローカライズの容易さは高得点だが、競合の薄さという最重要軸が低く、市場機会としては要観察(watch)止まり。参入するなら既存と同じ土俵での価格/機能勝負になり、個人開発者が新規に挑む合理性は乏しい。

判断ガイド

何をするか
macOS の全画面に透明オーバーレイを重ね、ペン・蛍光ペン・テキスト・矢印や図形でリアルタイムに描画できる注釈ツール。カーソルにリング/スクワークルのハイライトとクリックアニメを付与、画面の一部をスポットライトで強調、任意領域をズーム拡大できる。デジタルホワイトボード機能も搭載。Keynote・Google Slides・PowerPoint・Zoom・Google Meet・Teams・OBS など任意のアプリ/ファイル上で動作し、一定時間後に描画を自動消去する機能もある。典型用途はオンライン授業・ウェビナー・ソフトのデモ/ピッチ・録画チュートリアル制作。App Store・Setapp・Homebrew・直販で配布。
誰に刺さるか
オンライン家庭教師・講師、ウェビナー登壇者、SaaS のデモを行うセールス/CS、チュートリアル動画クリエイター、社内研修担当など、Mac で画面共有しながら説明する人。Windows の ZoomIt 相当を Mac で求める層。
再現可能性
medium — 全画面オーバーレイ、画面録画/アクセシビリティ権限、低遅延描画、各種会議アプリとの共存などネイティブ macOS の作り込みが必要。単機能だが品質バーは高く、競合が成熟している。

注目シグナル

  • 3 年以上の継続利用・継続開発のレビューがあり定着している
  • オンライン授業・リモート講師の実利用コメントが複数
  • Setapp/App Store/Homebrew/直販と配布チャネルが多彩
  • 買い切り中心で課金障壁が低い

懸念点

  • macOS の標準ズーム機能や OS 標準描画と機能が一部重複
  • 単機能ユーティリティで ARPU が低く LTV が伸びにくい
  • 国内外ともに同種アプリが飽和（ScreenPointer/DemoPro/ZoomIt 等）
  • Presentify 自身が既に日本の App Store で配布済みで新規参入余地が狭い
