国内既存プレイヤー

  • スイッチサイエンス(M5Stack正規代理店) — M5StickCPlus2等のESP32ボード本体を正規流通。Claude Buddy専用品ではないが、ハード調達の事実上の窓口でエコシステム側の最大プレイヤー。
  • ムーバクラウド ClaudeMate — Claude CodeをSlackから安全に遠隔操作するデスクトップアプリ。物理デバイスではないがClaude Codeの『離席中UX』問題への国産代替解。

規制要点

  • 電波法(技適): ESP32の無線モジュールを日本国内で電波発射するには技適が必要。M5Stack正規品(スイッチサイエンス流通)は取得済みだが、独自基板・改造ボードを販売する場合は工事設計認証が必要で個人開発にはハードルが高い。実験特例は半年限定。
  • 電気用品安全法(PSE): USB給電・付属ACアダプタを含めて販売する場合、PSEマーク対象となる可能性。個人輸入販売でPSE対応は費用・時間が大きく、現実的にはACアダプタは別売・ユーザー手配が無難。
  • 特定商取引法: オンラインでハード販売する場合、事業者表記・返品ポリシー・連絡先の明示が必要。Booth/BASE等は要件を満たすテンプレートを提供しており負担は小さい。

判断ガイド

何をするか
Claude DesktopアプリがmacOS/Windows向けに公開するBLE(Nordic UART Service)経由のローカルAPI。Claude CodeおよびClaude Coworkのセッション開始/終了、最近のメッセージ、tool permission promptなどを外部マイコンに通知し、承認/拒否をハード側ボタンで返せる。参照ファームウェアはESP32(M5StickCPlus)向けArduinoプロジェクトで、デスクペット型UI(待機・気にする・退屈・通知)を実装。仕様はREFERENCE.mdにNordic UART UUID・JSONスキーマ・folder push転送として公開され、自前デバイスを作る場合はリポジトリのコード自体は不要。eペーパー・カンバン・触覚デバイス・LEDタワー等ambient/playful表現の土台として位置付けられている。
誰に刺さるか
Claude Code/Coworkで長時間タスクを回す開発者、ESP32/M5Stack/xiaozhi-esp32系のメーカー、AIエージェント運用の通知・承認UXを物理デバイスで強化したいハッカー、AIガジェットを試作・発信したい個人・小規模ハードウェアスタジオ。
再現可能性
easy — BLE仕様とJSONスキーマが公開済み、参照実装(Arduino+M5StickCPlus)もOSS。ESP32系の安価なボードと電子工作の基礎があれば数時間〜数日で類似デバイスを再現可能。

  • GitHub Star 2k・Fork 315と短期間で活発(2026年4月公開)

  • Claude Code利用者の長時間タスク・権限承認UX問題に直接刺さる

懸念点

  • Anthropic公式OSSのため独自プロダクト化の余地が薄い(差別化が必要)
  • ハードウェア販売は技適/PSE/在庫リスクが個人開発に重い
  • Claude Codeへの依存度が高くAnthropicの仕様変更で陳腐化リスク
  • BLEペアリング・電源管理など個人運用の長期サポート負荷
  • 実際の課金導線が薄く、収益化シナリオが限定的
