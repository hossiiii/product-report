判断ガイド

何をするか
GPT-5.5 を核に据えた自律コーディングエージェント。従来の補完型コード生成に留まらず、ブラウザを実ユーザーのように操作してアプリを動かし、コンソール・ネットワークログを読んでバグを特定、自前で修正→再テストまで回す。Microsoft Office や Google Drive 上での資料生成、PC のクリック・タイピング操作にも対応するクロスアプリ型。macOS/Windows のデスクトップアプリと CLI、IDE 拡張で提供され、ChatGPT Plus/Pro/Business/Enterprise の各プランから利用枠が割り当てられる。Plus は 3 時間あたり最大160メッセージ、Pro は Plus の5倍、$200プランは20倍の枠。
誰に刺さるか
本格的なソフトウェアエンジニア、テックスタートアップの創業者、開発生産性を上げたい中堅以上の Web/SaaS 開発チーム。日本国内では既にメルカリ・サイバーエージェント・Ubie 等の大手・先進企業が Cursor/Devin と並列で導入を進めており、エンタープライズ層が主要ターゲット。
再現可能性
hard — GPT-5.5級のフロンティアLLMが必要で、個人や小規模チームでの再現は事実上不可能。OSSモデル＋エージェントフレームでも品質差は埋まらず、運用コストも個人運営では持続できない。

  • AI コーディング副業（Cursor/Claude Code 使用代行）に月10-50万円の需要

懸念点

  • OpenAI 本家プロダクトで個人開発者の参入余地ゼロ、競合は Anthropic/Google/Microsoft/Cursor/Devin
  • Codex に GitHub トークン窃取の脆弱性が2026年3月に発覚、企業のソースコード入力は警戒継続
  • PLG 経由で本家に直接顧客が流れる構造、ラッパー型サードパーティは差別化困難
  • コモディティ化が2026年に本格化し、薄い付加価値のAIサービスは淘汰局面
  • 個情法・契約上の秘密保持義務との抵触可能性、企業導入は法務確認が必須
