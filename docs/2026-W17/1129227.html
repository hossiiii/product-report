国内既存プレイヤー

  • iステップ — Meta 公式 API ベース、月額 22,000 円(年契約 16,500 円)、通数無制限。令和の虎・稲葉信氏が開発で認知が高く、上場企業から個人事業主まで採用実績
  • エルグラム — Meta 公式 API、スタンダードプラン月額 11,000 円。導入実績 1 万件超、ユーザー数 3000 超。フリープラン 1000 通/月の安価帯で個人事業主層を獲得
  • SAKIYOMI チャット — Instagram 専用 DM 自動送信。キーワード/リアクション条件で最適メッセージ送信。SAKIYOMI 運用代行のクロスセル経路を保有
  • BEEAM (プロパゲート) — DM 自動送信ツール。アカウント BAN 対策と運用代行サポートを訴求

規制要点

  • 個人情報保護法: DM 内で名前/メール/電話/予算/予約日時を収集・保存するため、利用目的の明示・保管期間・第三者提供・委託管理(米国/EU リージョンサーバ利用時の越境移転)対応が必須。プライバシーポリシー整備と DPA 整備が必要
  • 特定電子メール法: 消費者庁見解で対象は電話番号/SMTP 経由のメッセージに限定されるため Instagram DM 自体は規制対象外。ただし DM 中で取得したメールアドレスへ営業メールを送る場合はオプトイン必須
  • 景品表示法・特定商取引法: DM 配信内容が広告に該当する場合、優良誤認/有利誤認の表示規制、価格表記、定期購入の表示義務が適用。自動応答の誤回答による誤認表示リスク管理(ログ保持・運営者責任)が必要
  • Meta プラットフォームポリシー: Messaging API の 24 時間応答ウィンドウ、ブロードキャストの事前承認、スパム検出によるアカウント制限。公式 API アプリレビューを通過しないと商用提供不可で、申請には実利用デモが必要

機会: 国内競合(iステップ/エルグラム)は『DM 自動返信+簡易フロー』に強いが、AI エージェントによる動的応答・知識ベース(RAG)・MCP 連携・AI フロー生成の体験はまだ薄い。差別化角度は (1) 日本語 RAG 特化(店舗マニュアル/EC 商品 DB を Insta DM で問い合わせ対応)、(2) LINE 公式アカウントとのクロスチャネル運用、(3) Shopify Japan/BASE/STORES など日本 EC への直結、(4) 美容/サロン/コーチ等の業種別テンプレ提供。ただし PLG だけでは代理店ネットワークに勝てず、運用代行会社と OEM 提携する経路が現実的

市場機会総評: 需要面では Instagram が日本の中小・EC・クリエイター向け最有力チャネルで、DM 自動化の市場は確実に拡大している。一方、国内には Meta 公式 API ベースの確立競合が複数存在し、月額 1.1〜2.2 万円という ARPU 帯で価格競争が始まっている。Inrō 本体のグローバル価格(€12.99〜)を考えると、コア機能の優位性(AI Agent・MCP)は強いものの、後発の個人開発者が日本市場で独自プロダクトを立てる場合は、競合不在カテゴリではないため『差別化×ニッチ業種特化』が必須。watch スコア相当だが市場機会自体は否定しない
