国内既存プレイヤー

  • Codex Pets (OpenAI 公式) — 本プロダクト自体。OpenAI 純正・無料で日本からも利用可。
  • Claude Code Buddy — Anthropic 公式の同系統機能。18 種 5 レアリティで先行、Pro 加入者向け。
  • codex-pets (OSS) — MIT ライセンス、200+ ペット、Codex/Claude Code/Cursor 横断対応。完全無料の代替。
  • petdex — 1155+ カスタムペットが集まるコミュニティギャラリー。素材供給側を独占しており差別化が困難。
  • Desktop Mate (infiniteloop) — 国内発デスクトップマスコット PF。リリース 2 週で 100 万 DL、DLC キャラ販売モデルが既に確立。

規制要点

  • 著作権法 / 二次創作ガイドライン: 既存キャラを模したペット配布は権利侵害リスク。ユーザー生成ペットの流通プラットフォームにすると DMCA/権利者対応コストが発生する。
  • 景品表示法・資金決済法 (ガチャ要素を入れる場合): レアリティ × 有料ガチャでマネタイズする場合、確率表示や前払式支払手段の登録など追加対応が必要になる可能性がある。

機会: 和風ペット（妖怪・地域キャラ・干支等）に特化したスプライト/スキンパックを petdex に投稿し、知名度獲得→自身の有料スキルやアセットを訴求する『コンテンツ起点リード獲得』に留めるのが現実的。SaaS 本体の機会は乏しい。

市場機会総評: 本機能は OpenAI が公式提供し OSS 代替も無料という、典型的な『プラットフォーマーがコモディティ化した領域』。日本側でも Desktop Mate という強力な既存 PF が DLC 課金モデルを確立しており、新規参入者がポジションを取る余地はほぼない。需要自体は『あれば楽しい』程度で支払い意欲は低く、規制は緩いが収益化の論理が成立しない。

判断ガイド

何をするか
OpenAI Codex デスクトップアプリの設定で有効化できる、フローティング型アニメーションペット機能。Codex の実行/待機/レビュー待ち状態をマスコットの動作で表現し、開発体験を遊び心ある方向に拡張する。/pet トグル、/hatch でカスタム生成、Cmd+K で表示切替。hatch-pet スキルや petdex ギャラリーを介して 200 種以上のカスタムペットが流通する。
誰に刺さるか
Codex / Claude Code / Cursor を日常的に使う個人開発者・趣味プログラマ。エージェント実行中の待ち時間を可視化したい層、デスクトップ装飾やゲーミフィケーションを好む層。
再現可能性
medium — Electron + スプライト管理 + プロセス状態フックで実装可能。ただし Codex/Claude Code への接続部分はベンダー API/プロトコル理解が必要。

注目シグナル

  • Product Hunt で 283 upvotes と開発者コミュニティで好反応
  • Claude Code Buddy と同系統の流れ、petdex に 1155+ のカスタムペットが集まる
  • OpenAI 自身が公式機能として標準搭載するほど需要を認識
  • MIT ライセンスの codex-pets OSS が並行して登場、エコシステムが拡張中

懸念点

  • OpenAI 純正機能と完全 OSS 代替が既に無料で存在し、後発の独立 SaaS 化は困難
  • 本体が無料・OSS なため直接課金は難しく、装飾/ガチャ要素しか収益源がない
  • プラットフォームベンダー（OpenAI/Anthropic）が機能を拡張するとサードパーティは即座に陳腐化
  • 日本市場特有の差別化ポイントが薄く、グローバル OSS 化が前提になりやすい
