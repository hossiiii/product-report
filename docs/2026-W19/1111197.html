判断ガイド

何をするか
VS Code 拡張として動作する AI コーディングエージェント。OpenCode サーバーをコアに据え、複数ツール呼び出しの並列化、複数サブエージェントを git worktree で隔離して並走させる Agent Manager、エージェント差分への行単位レビュー、複数モデル同時比較、CLI とのセッション共有を提供する。Cline と Roo Code を起点に派生したプロジェクトで、500+ モデルをプロバイダ実費（マークアップなし）で接続できる。
